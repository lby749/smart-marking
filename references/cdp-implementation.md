# 通过 CDP 实施阅卷

这是本机曾实际使用的操作路线，供后来接手的 Agent 参考；它不是对所有浏览器或智学网版本的 API 承诺。只连接用户授权的会话，不能绕开认证、验证码、浏览器许可或使用其他用户的浏览器配置。先查看任务的现有工具与实际页面，再决定是否沿用这些代码。

## 1. 找到已有会话并保持连接

1. 先确认用户指定的浏览器、目标页面 URL、题号和授权范围。查找已存在且属于该浏览器的调试端点或现成的持久连接；若已有可用桥接，直接沿用，不要每份卷或每次工具调用都重新启动连接。不得重启浏览器、覆盖用户资料目录或复制 Cookie 来强行接入。
2. 本机这次 Edge 会话使用了 `%LOCALAPPDATA%\Microsoft\Edge\User Data\DevToolsActivePort`：第一行是端口，第二行是浏览器 WebSocket 路径；Chrome 的用户数据位置不同。如果文件不存在、过期、端点不通或权限未开放，不能据此断言用户未登录，也不能绕过权限；排查实际进程、当前用户数据目录、支持的调试入口或使用已授权的浏览器工具。不要把文件内容、完整 WebSocket 地址、端口令牌或 Cookie 输出到日志或聊天。
3. 随技能发布的 `scripts/cdp_bridge.py` 用持久的 Python 进程调用 `playwright.chromium.connect_over_cdp`，从用户已授权的 `DevToolsActivePort` 读取端点，并只选与用户输入的完整 URL 唯一匹配的页面。匹配到多页必须先消除歧义，不随意选第一项。浏览器需要已经开放对应调试入口；脚本不会自动开启、登录或绕过许可。
4. 桥接通过标准输入接收逐行 JSON，提供 `state`、`eval`、`capture` 和 `close`。代理要保留进程句柄，串行发送请求并读取响应；若需要额外 IPC，必须自行确保唯一消费者和请求对应，不能把某次会话的进程号、页面 ID 或图片索引写死。`eval` 可执行页面 JavaScript，因此调用方负责授权、评分与提交前后的核验；桥接不调用模型，也不自动提交。
5. 用完只断开本工具建立的连接；不要调用会关闭用户浏览器或页面的方法。不能确保关闭语义安全时，先查当前 Playwright 版本与项目实现。

先安装 Python 依赖 `python -m pip install playwright Pillow`；`connect_over_cdp` 连接现有浏览器，不需要脚本启动新浏览器。用户已授权且确实没有现成桥接时，从技能目录启动以下**持久**进程：

```powershell
python -X utf8 .\scripts\cdp_bridge.py --port-file "$env:LOCALAPPDATA\Microsoft\Edge\User Data\DevToolsActivePort"
```

启动后先向标准输入发送一行 `{"target_url":"<授权阅卷页完整URL>"}`；URL 不放在进程参数或共享日志中。收到 connected 后，在同一进程中逐行请求、逐行读取 JSON 结果：

```json
{"op":"state"}
{"op":"eval","code":"() => document.title"}
{"op":"capture","frame":0,"selector":"#当前答题图片的唯一选择器","output":"answer.png"}
{"op":"close"}
```

选择器、frame 和输出路径必须根据实际页面与环境替换；`eval` 可读写页面，只在用户授权范围内运行。`capture` 返回本地图像路径、摘要和来源，随后用图像查看工具打开该路径。示例命令应由 Agent 的持久进程工具逐条发送，不要把上面的多行请求误当成 PowerShell 命令。进程结束会断开 Playwright，未调用 `browser.close()` 关闭用户浏览器。

## 2. 建立当前答卷快照

- 读取 URL、题号、总分、阅卷进度、当前输入值及提交按钮是否可用。对于页面含 iframe 的情况，先确认实际答卷所在 frame；不要假设顶层文档或固定图片序号。
- 通过页面已存在的 DOM/组件状态获取当前题目和答卷标识。本次智学网页面中，曾通过 `#topicImg0` 的祖先 Vue 组件访问 `topicInfo.item.id`；这是内部实现，不是稳定接口。只在本机比较其 SHA-256 摘要，不输出原始学生标识。
- 记录当前答卷的标识摘要、题目、满分、页面状态、题图摘要和图像来源，建立一份快照。读取教师题目与评分标准并缓存；每份只送入当前相关图片，不把全部学生答案留在主上下文。

## 3. 获取原图并交给模型

随技能发布的 `scripts/cdp_bridge.py` 的 `capture` 可使用唯一 CSS 选择器按以下顺序读取原图：

1. 从目标 frame 的 `img,canvas` 定位**当前答题元素**，以当时 DOM 计算索引；确认 `img.complete`、`naturalWidth`、`naturalHeight` 均有效。不要写死某次的索引：页面插入图或换卷时索引会变。
2. 页面上下文中对已加载的图片地址 `fetch`，或对可读取的 canvas `toBlob`，用 `FileReader` 将字节交回本地；浏览器跨域限制生效时不要绕过。只处理页面当前可访问的资源。
3. 上一步因 CORS 等失败时，本次实现对**页面已加载的同一图片**用该浏览器上下文的 `context.request.get` 读取，校验 HTTP 状态、图像格式和像素尺寸；不得将 Cookie 或签名 URL 打印、写进技能或泄露。两种获取方式均不可用时，按用户允许的方式请求复核或有界局部截图，不默认全屏截图。
4. 将图像保存到访问受限的临时目录，以路径调用当前 Agent 的图像查看工具，或由 MCP 返回 Image Content。只返回 URL 不能证明模型看到了图片；OCR 结果只能辅助，必须检查原图。图片如跨页、作文很长或答题区截断，应补齐全部所需区域，不得把低分辨率缩图当完整证据。
5. 本次智学网的截断答题图曾可通过页面组件内的 `topicInfo.detail.paperImgIds`、`cutBlock.coordinate` 和页面正常调用的 `https://pt-ali-bj.zhixue.com/exam/common/getFullImageUrl` 补取：在页面授权上下文中以 `originalUrls`、`coordinate`、`type=part` POST，检查返回成功，再读取对应原图。响应与坐标随题目和网站变化，切勿复用他人链接或将本次裁切像素常量推广到其他题。临时 DOM 图片必须隐藏，加载后按需提取并移除；不要覆盖答卷或改变用户浏览体验。
6. 原始文件编码不同可能导致字节哈希变化：先确认来源、图片尺寸及解码后像素，再结合答卷 ID 判断是否相同；绝不能据此忽略换卷风险。

## 4. 评分、回填和验证

- 视觉识别及评分由当前 Agent 或用户授权的子代理完成，依据教师规则记录得分点、分数、必要的推断及复核标记。不是让浏览器脚本调用模型。
- **提交前同一份答卷**：重新读答卷 ID 摘要、题号、满分、进度、空分/原分及当前图片，必须与识别时的快照一致；若任何一项不一致，不填分。
- 本次页面曾使用 `#txt_marking_11` 和 `#bnt_save`；不同题号和版本可能不同，先检查实际输入和按钮。通过 `HTMLInputElement.prototype.value` 的原生 setter 填分，触发冒泡的 `input` 与 `change`，读回显示值；确认一致后才点击提交**一次**。可在一个 `page.evaluate` 中依次核验、赋值、读回、点击，减少跨进程往返，但仅限用户已授权提交，且先完成页面权限和状态核验。
- 对成功提交，使用条件等待而非固定延时：核验页面进度递增、答卷 ID 变化和新答题图就绪。若超时或结果未知，保留原进程句柄，等待其结束并只读查询页面及网络状态，切勿直接重试。再次点击仅在充分证据确认先前未生效、无未完成请求且当前卷状态安全时进行。
- 回评时先确认原 ID 和当前平台分数。平台出现回评完成确认时，按可见界面完成必要确认；然后离开再重新进入同一 ID 读回结果。只读到输入框值或进度变化，不应声称平台保存值已逐条复核。

## 5. 性能、隔离和数据记录

- 对不变题目与标准缓存；条件等待、复用连接、合并安全读取。耗时应按取图、OCR/视觉判断、填分提交、等待换卷分段记录，另外记录端到端耗时、重试及复核；中断或缺少起点时填未知，不能把“提交段耗时”冒充整份耗时。
- 用户当前偏好是根据运行时报告的上下文窗口，达到约 60% 时在安全边界切换；具体用量需由宿主 Agent 的可靠遥测获得，本技能未提供跨平台统一的用量读取程序。切组不关闭 CDP 连接；新代理启动时合理的缓存未命中不等同持续速率异常。用户要求监测时，检查本对话和当前子代理的输入、输出及缓存变化率；异常暂停调查，短时恢复且页面安全后自动继续。
- 最小化保存学生信息，记录匿名 ID 摘要、题图摘要、分数与依据、提交前后状态、复核标记；按用户要求控制保存期限。历史本地日志可能早于教师回评，做反馈统计优先读取平台当前分数，说明样例和统计口径。
