# 智学网阅卷的实测经验

本说明记录一次真实授权的智学网网页阅卷及本地开发经验，不承诺适用于其他账号、题型、站点版本或机器。只使用当前用户合法可访问的页面和接口，不输出或转移 Cookie、签名链接、学生标识或原图到无关服务。

## 现有资源与连接

技能自带的 [CDP 桥接脚本](../scripts/cdp_bridge.py) 提供可复用的基础连接和原图读取。具体题号识别、评分和提交需要针对当前页面核对后由宿主 Agent 完成，不能假设 session ID、端口、页面结构或窗口大小固定。不得为复用绕过当前工具或平台安全限制。

曾在页面 Vue 组件中通过题目信息读取答卷相关 ID 和图像资源，并使用平台的原卷图片接口补全截断内容。只在当前用户已授权且网页本身可访问的范围内运行；以实际页面结构和请求为准。图片请求成功不等于图已加载：条件等待 `complete` 与有效尺寸，按当前 DOM 重新确定索引。临时图应隐藏、移除，绝不能覆盖用户页面；需要评分的区域必须完整且清晰。

## 常见故障与处理

- **只读取图失败或截断**：核对答卷 ID、资源加载状态和当前图片索引，再安全重试只读操作。一个案例中插入隐藏图导致图片索引变化；另一个案例临时图误显示在页面，清理后恢复。不要固定假定某一索引永远对应答案。
- **同图哈希变化**：不同抓取路径可能产生不同编码；核对真实来源、尺寸和解码后的像素，再结合答卷 ID 判断，不能因字节哈希不同就认定换卷，也不能跳过题卷对应核验。
- **提交后等待超时**：保留工具 session ID 并等待正在运行的进程，不并发发起第二次提交。进程结束后查询进度、答卷 ID、分数及加载状态；平台状态稳定且证据足够时才恢复。请求可能已经发出而响应丢失，不可简单把超时当作失败。
- **回评未保存**：一次实测中仅点击提交后直接导航，回到同一答卷仍是旧分；平台出现回评结束提示时，按当次界面完成相应确认，再离开并重入同一 ID 读回。弹框按钮和行为以当前页面为准，不能一律盲点。
- **筛选复位**：阅卷记录面板关闭并重开时曾默认返回“全部得分”，而改分又会让记录从原筛选中消失。注意用户当前筛选，恢复期望筛选并记已核验 ID，别因为列表移动而跳漏；平台统计和本地历史日志分别核对。
- **转接超时与断开**：曾因 IPC 轮询次数上限耗尽导致转接退出，已去除固定上限；读取异常应分辨尚在运行的操作、迟到的只读响应与真正未发出的请求。保留稳定浏览器连接，避免重新连接引起重复授权。
- **自动化速率误报**：旧规则把新代理的首次缓存未命中当作异常，造成不必要停顿。使用近期变化率与合理基线，区分启动期一次性加载和持续异常；异常后安全检查并按用户指示自动恢复。
- **评分过严**：一次阅卷将评分示例里的“举具体词语”误当作必须条件，造成已写正确手法的答案被低估，甚至错误回评为零分。应先按教师明确口径改正，不要求与示例一致；回评须核对用户可能已自行改过的实际分数。

## 反馈数据

平台完成量不等于每条分数均已重新回读；旧阅卷日志也可能落后于教师回评。若制作图表，优先读取平台当前筛选总数，核对各档之和与统计范围；若使用历史日志或仅部分样本，应清楚标注范围和局限。样例裁切仅保留需要讲评的答题区域，去除身份信息，分析不能超出可见证据。
